Análise por PDF do e-CAC

Envie os documentos exportados do e-CAC. O sistema extrai os dados automaticamente via IA e gera o diagnóstico fiscal.

Documentos aceitos

  • Declaração SIMEI
  • DAS e-CAC (guias mensais)
  • PGDAS-D (Declaração Anual)
  • Comprovantes mensais de receita

Os dados são processados via Claude Vision API e não são armazenados permanentemente. Máximo de 10 arquivos por envio, 50 MB por arquivo.
